# Research execution prompt package

Prepared on 28 September 2026 after reviewing both PDFs, both referenced tasks,
the current source, workflow, tests and saved experiment artifacts.

Copy this into the main ML-TradeEngine task when you want execution to begin:

```text
Execute /Users/a/Downloads/ml-trade-engine/docs/research-brief/EXECUTION_PROMPT.md.
Read its companion EVIDENCE_AND_TEST_PLAN.md and REVIEW_NOTES.md first.
Merge AGENTS.proposed.md into the repository's AGENTS.md without discarding
existing instructions. Work through the research and operational requirements,
run the necessary experiments and tests, configure the specified local shadow
collection schedule, and produce the complete paper and reproducibility package.
Proceed with authorized local work; preserve existing changes and sealed releases.
Keep external broker orders disabled. Separate work completed now from the
prospective evidence that must accumulate later. Do not substitute a short
readiness summary for the requested empirical research paper.
```

- `EXECUTION_PROMPT.md`: the main implementation and research brief.
- `EVIDENCE_AND_TEST_PLAN.md`: required analyses, data, tests and task schedule.
- `AGENTS.proposed.md`: concise persistent rules, ready to merge at repository root.
- `REVIEW_NOTES.md`: findings that explain these requirements and source locations.

This package is a specification. Its creation did not train new models, run the
test suite, activate a scheduler, edit trading code, or replace a sealed release.
The proposed AGENTS file is deliberately inactive until the main task applies it.

Success means a working, observed collection pipeline and a complete, deeply
analyzed manuscript. Statistical evidence may support positive or negative
findings. Profitability is a separate empirical result, never an acceptance quota.
